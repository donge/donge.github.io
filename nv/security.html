Trap group / Policer

Trap groups / policers

Hostif trap 选择上送原因，trap group 可绑定 CPU queue/policer。

Hostif traps select punt reasons; groups can bind CPU queues/policers.

Policer 的 CIR/PIR、CBS/PBS 与 meter type 决定 token 预算；pps 与 bytes/s 模式的相同数值含义不同，必须核对 API 单位。

CIR/PIR, CBS/PBS and meter type determine token budgets. The same number means different things in packet-rate and byte-rate modes; check API units.

ACL key / action

ACL keys / actions

Ingress/Egress ACL stage 支持字段与动作可能不同，L3/L4 key、mask、priority、counter 与 packet action 独立配置。

Ingress/egress stages may support different fields/actions.

多条重叠规则的优先关系必须明确；范围对象也可能消耗额外硬件资源。

Keys, masks, priorities, counters and packet actions are separately configured. Define overlap precedence; range objects can require extra hardware resources.

MACsec 与 IPsec

MACsec & IPsec

MACsec 保护以太网链路帧，常见 EtherType 0x88E5，涉及 SecTAG、packet number、ICV 与 replay protection；SCI 可标识安全通道。

MACsec protects Ethernet links, commonly using EtherType 0x88E5, SecTAG, packet numbers, ICV and replay protection; SCI identifies a secure channel.

它不是 VXLAN 类租户封装，也不应与 IPsec 的 IP 层隧道混同。

It is neither VXLAN tenant encapsulation nor an IPsec-layer tunnel.

uRPF / 源验证

uRPF / source validation

Strict uRPF 检查源地址反向最佳路径是否对应入口，loose 通常要求存在可接受源路由。

Strict uRPF checks reverse-path ingress consistency; loose mode generally requires an acceptable source route.

非对称路径使 strict 模式可能丢弃合法流量。DHCP snooping/DAI 等还依赖绑定表，不能只靠目的 ACL 替代。

Asymmetry can make strict mode drop legitimate traffic. DHCP snooping/DAI depend on bindings and cannot simply be replaced by destination ACLs.

控制面资源耗尽模型

Control-plane exhaustion model

攻击报文可通过 trap 消耗 CPU、队列、邻居或日志空间。为每个入口定义分类和上送策略、速率/突发配额、状态表上限和丢弃计数。仅限制 pps 仍可能遗漏高成本报文；按处理成本与合法协议需求做分级预算，并验证正常邻接不会被防护误伤。

Trapped packets can exhaust CPU, queues, neighbors or logs. Define classification/punt policies, rate/burst budgets, state limits and drop counters per ingress. Pps limits alone may miss expensive packets; budget by processing cost and legitimate protocol needs and verify valid adjacencies survive.
