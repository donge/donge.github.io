路由进程

Routing processes

bgpd 维护 BGP 邻接和路径；zebra 管理路由并向内核/FPM 导出；fpmsyncd 接收 FPM 写应用数据库；orchagent 按依赖创建 SAI 状态。

bgpd maintains peers/paths; zebra manages routes and exports to kernel/FPM; fpmsyncd writes application state; orchagent builds SAI state from dependencies.

协议容器与 SWSS 的边界是真实 IPC，不是单个函数调用。

Protocol-container/SWSS boundaries involve IPC rather than a single call stack.

五类数据库

Five database roles

CONFIG_DB 保存配置输入，APPL_DB 保存应用产生状态，STATE_DB 提供运行/依赖状态，ASIC_DB 保存面向 ASIC 的对象表达，COUNTERS_DB 保存统计。

CONFIG_DB stores configuration, APPL_DB application state, STATE_DB operational/dependency state, ASIC_DB ASIC-oriented objects and COUNTERS_DB statistics.

它们不是同一数据的五份即时镜像。

They are not five instantaneous copies of the same information.

SAI Redis / syncd

SAI Redis / syncd

SAI Redis 层可序列化对象操作；syncd 消费硬件方向操作并调用厂商 SAI。

SAI Redis can serialize operations; syncd consumes hardware-directed requests and invokes vendor SAI.

虚拟 ID 与真实 ID 映射用于跨层识别对象；通知也需要反向映射。同步/异步通信方式需按目标版本配置核对。

Virtual/real IDs identify objects across layers and notifications need reverse mapping. Verify synchronous/asynchronous modes for the deployed version.

统计采集

Statistics collection

Counter 由 ASIC/SDK 暴露，经统计采集组件写入 COUNTERS_DB，采集周期带来时间差。

ASIC/SDK statistics are collected into COUNTERS_DB with sampling delay.

计数器可能累计、清零读取或按硬件块聚合；“Redis 没变化”可能是采集停滞，不等于线路无流量。

Counters may accumulate, clear on read or aggregate hardware blocks. Unchanging Redis values may indicate stalled collection rather than no wire traffic.

路由下发链路走读

Walking the route-programming path

为前缀记录配置/协议来源、应用库键、orchagent 依赖、SAI 对象关系、syncd 结果及硬件条目。每阶段可能接受但尚未完成；排障时报告“卡在哪一阶段、等待谁、队列多久”，比“数据库里有”更可执行。具体数据库与进程路径以目标 SONiC 分支为准。

Track a prefix's config/protocol source, application key, orchagent dependencies, SAI object graph, syncd result and hardware entry. Acceptance may precede completion at each stage. Report the blocked stage, dependency and queue age, not merely database presence. Follow the target SONiC branch's exact paths.
