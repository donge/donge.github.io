三种地址

Three address spaces

CPU virtual、CPU physical 与 DMA bus address 不能互换。

CPU virtual, physical and DMA bus addresses are not interchangeable.

dma_map_single 返回 dma_addr_t，IOMMU 可建立不同映射；设备描述符必须写设备可见地址，而不是强制转换普通指针。映射长度与方向影响同步。

dma_map_single returns dma_addr_t and IOMMUs may translate it. Descriptors need device-visible addresses, not cast pointers. Mapping length/direction affects synchronization.

Coherent / Streaming

Coherent / streaming

Coherent allocation 为共享控制结构提供一致性，但仍可能需要写入顺序屏障。

Coherent allocations provide coherence for shared controls but can still require ordering barriers.

Streaming mapping 适合数据缓冲，CPU/设备切换访问时按 API 同步；DMA_TO_DEVICE、FROM_DEVICE、BIDIRECTIONAL 不是随意可替换的标志。

Streaming mappings suit data buffers and require ownership-aware synchronization. DMA_TO_DEVICE, FROM_DEVICE and BIDIRECTIONAL are not interchangeable hints.

RCU API 语义

RCU API semantics

读侧 rcu_read_lock/unlock 保护相应访问区间；更新侧先移除发布引用，再通过 synchronize_rcu 或 call_rcu 等等待既有读者结束后回收。

RCU read-side critical sections protect corresponding accesses.

RCU 不自动序列化所有 writer，也不保证读者看到跨对象原子快照。

Writers remove published references then wait via synchronize_rcu/call_rcu before reclamation. RCU neither serializes all writers nor guarantees a multi-object atomic snapshot.

Cacheline 与 NUMA

Cache lines & NUMA

多 CPU 更新同一 cacheline 上不同计数器也会产生 false sharing。

CPUs updating different counters on one cache line can false-share.

per-CPU 统计减少写竞争但读取需聚合；RX queue、IRQ CPU 与内存节点不对齐会增加跨 NUMA 访问。锁竞争与 cacheline bouncing 是不同但相关的成本。

Per-CPU counters reduce writes but need aggregation. Misaligned RX queue/IRQ CPU/memory placement adds NUMA traffic. Lock contention and cache-line bouncing are related but distinct costs.

发布与回收是两个问题

Publication and reclamation differ

发布需要读者看到完整初始化对象；回收需要所有旧读者已结束。即使指针赋值是原子的，也不能证明对象字段可见或释放安全。明确采用锁、引用计数或 RCU 的责任：锁保护哪个不变量、引用覆盖哪段异步生命周期、RCU grace period 后才释放哪块内存。

Publication requires readers to see initialized fields; reclamation requires old readers to finish. Atomic pointer assignment proves neither visibility nor safe freeing. Define which invariants locks protect, which asynchronous lifetimes references cover and which memory awaits an RCU grace period.
