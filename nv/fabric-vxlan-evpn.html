VXLAN 报头

VXLAN header

VXLAN 基本头 8B，包含 flags 与 24bit VNI；常见 UDP 目的端口 4789。

The basic VXLAN header is 8B with flags and a 24-bit VNI; UDP destination commonly uses 4789.

VTEP 使用外层 IP 路由，内层 Ethernet 保留租户语义；UDP 源端口可提供 hash 熵，但具体生成方式依实现。

Outer IP routes between VTEPs while inner Ethernet carries tenant semantics. UDP source ports can supply hash entropy; generation is implementation-specific.

EVPN 路由类型

EVPN route types

Type 1 为 Ethernet A-D，Type 2 宣告 MAC/IP，Type 3 为 Inclusive Multicast Ethernet Tag，Type 4 为 Ethernet Segment；Type 5 IP Prefix 来自扩展规范 RFC 9136。

Type 1 is Ethernet A-D, Type 2 MAC/IP, Type 3 Inclusive Multicast Ethernet Tag, and Type 4 Ethernet Segment.

不同类型服务于发现、可达性、复制与多归属，不应统称“MAC 路由”。

Type 5 IP Prefix is specified by RFC 9136. Types support discovery, reachability, replication and multihoming rather than all being MAC routes.

RD / RT / VNI

RD / RT / VNI

RD 使不同租户重叠前缀的 VPN 路由可区分；RT 承载导入/导出策略；VNI 标识数据面虚拟网络。

RD distinguishes overlapping VPN routes, RT carries import/export policy, and VNI identifies the data-plane virtual network.

三者不是同一个 ID。IRB 连接二层桥接域与三层路由，L2VNI/L3VNI 映射与网关 MAC 决定跨子网路径。

They are not interchangeable IDs. IRB joins bridging/routing; L2VNI/L3VNI mappings and gateway MAC determine intersubnet paths.

封装 MTU 算例

Encapsulation MTU example

内层 1500B IP+14B Ethernet，不含内层 FCS；外层 IPv4 20B+UDP 8B+VXLAN 8B，因此 underlay IP 包为 1550B。

A 1500B inner IP packet plus 14B Ethernet, excluding inner FCS, with outer IPv4 20B+UDP 8B+VXLAN 8B yields a 1550B underlay IP packet.

再加外层 Ethernet/FCS 才是线上帧；内外 VLAN 或 IPv6 会改变数字。

Outer Ethernet/FCS adds wire overhead; VLANs or IPv6 change the calculation.

封装字节预算

Encapsulation budget

VXLAN over IPv4 的常见外层增加 14B Ethernet+20B IPv4+8B UDP+8B VXLAN，不含额外 VLAN 和外层 FCS。内层携带 Ethernet 帧而不是仅 IP 包，因此 underlay 的 L3 MTU 需要容纳外层 IP/UDP/VXLAN 和内层二层报文。应逐字段计算，明确设备 MTU 命令的口径，避免把“增加 50B”机械用于所有场景。

Typical VXLAN over IPv4 adds 14B Ethernet+20B IPv4+8B UDP+8B VXLAN, excluding extra VLAN tags and outer FCS. The inner payload includes Ethernet, not just IP, so underlay L3 MTU must cover outer IP/UDP/VXLAN plus the inner frame. Calculate fields explicitly and verify each device's MTU definition rather than applying a universal 50B rule.
