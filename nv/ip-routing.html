LPM 算例

LPM example

同一 VRF 中 10.0.0.0/8→A、10.1.0.0/16→B、10.1.2.0/24→C，目的 10.1.2.8 命中 C。

In one VRF, /8→A, 10.1/16→B and 10.1.2/24→C send 10.1.2.8 to C.

先进行路由表/VRF 选择再做最长匹配；ACL 优先级与路由 prefix 长度是不同匹配语义。

Select VRF/table before longest-prefix matching. ACL priority and route-prefix length are different matching semantics.

BGP 状态与消息

BGP states & messages

Idle→Connect/Active→OpenSent→OpenConfirm→Established；OPEN 协商参数，KEEPALIVE 维持会话，UPDATE 宣告/撤销路径，NOTIFICATION 报错。

Idle→Connect/Active→OpenSent→OpenConfirm→Established.

Established 不代表某前缀通过策略，也不代表 FIB 已编程。

OPEN negotiates, KEEPALIVE maintains, UPDATE announces/withdraws, and NOTIFICATION reports errors. Established proves neither prefix-policy acceptance nor FIB programming.

邻居 NUD 状态

Neighbor NUD states

Linux 常见 INCOMPLETE、REACHABLE、STALE、DELAY、PROBE、FAILED。

Linux states include INCOMPLETE, REACHABLE, STALE, DELAY, PROBE and FAILED.

STALE 并不等于不能发送，后续可达性确认会触发探测；ARP 用 IPv4 地址解析，IPv6 ND 使用 ICMPv6 NS/NA，不能混同为广播 ARP。

STALE does not mean unusable; later reachability checks trigger probing. IPv4 uses ARP, while IPv6 ND uses ICMPv6 NS/NA rather than broadcast ARP.

MTU / 分片 / ICMP

MTU / fragmentation / ICMP

IPv4 DF 阻止路由器分片时，过大报文需适当 ICMP 反馈；IPv6 路由器不分片，源端依据 Packet Too Big 调整。

IPv4 DF can require ICMP feedback for oversized packets; IPv6 routers do not fragment and sources react to Packet Too Big.

只测试小 ping 会漏掉 MTU 黑洞；IPv4 options 与 IPv6 extension headers 还影响解析与 offload。

Small pings miss MTU black holes. IPv4 options and IPv6 extension headers also affect parsing/offload.

路由对象依赖链

Route dependency chain

以 VRF blue 中 10.2.0.0/24 为例：选路得到下一跳 192.0.2.2，递归解析其出口接口，再通过邻居记录得到目的 MAC，构造 rewrite，加入下一跳组，最终安装前缀引用。任一依赖失败都可能导致“协议路由存在但不能转发”，所以诊断输出应展示依赖就绪状态。

For 10.2.0.0/24 in VRF blue, selection yields next hop 192.0.2.2, recursion resolves the interface, neighbor state supplies destination MAC, rewrite is built, the group is populated and the prefix references it. Any missing dependency can leave a protocol route without forwarding; diagnostics should expose dependency readiness.
