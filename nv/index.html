控制面到 ASIC

FRR→硬件路由：FRR bgpd 处理 BGP，zebra 管理路由选择及下发。

控制报文与 CPU：Trap 将特定报文送 CPU，copy/mirror 可保留原转发并复制。

路由间接寻址：前缀→next-hop group→member→next hop→router interface/neighbor→MAC rewrite。

命令队列与 DMA：MMIO doorbell 通知设备存在新命令；命令内容可通过 DMA 描述符/缓冲传递。

ASIC 资源与规模

SRAM / TCAM / LPM：Exact match 常用 hash/SRAM，ternary 规则需要掩码匹配，LPM 可由多种专用或组合结构实现。

Buffer cell 算账：若 cell 大小 C、包需缓存 L 字节，简化成本是 ceil(L/C)×C，另加实现 metadata。

ECMP 资源：资源至少包含组对象、成员对象、hash buckets 和 next-hop/rewrite。

PPS 与内部遍历：回流、镜像、多播会放大内部工作量。

ASIC Pipeline 与查表

Parser / Metadata：Parser 根据 EtherType、IP protocol、UDP 端口等识别层级，提取 key 与内部 metadata。

TCAM 匹配语义：ternary 位可为 0、1、don't-care，结合优先级决定重叠规则命中。

Rewrite 与校验和：L3 转发更新 TTL/Hop Limit 和二层地址；IPv4 还需更新头校验和，IPv6 没有该头校验和。

TM / VOQ / 调度：Buffer 保存报文或 cells，descriptor 记录队列与元信息，scheduler 决定何时服务哪个队列。

SAI 对象与属性

Route 是 keyed entry：sai_route_entry_t 的键为 switch_id、vr_id、destination；创建路由不返回新的 route OID。

Buffer 对象关系：Buffer pool 表示容量及 ingress/egress 类型；profile 引用 pool 并定义预留与阈值；ingress priority group 或 queue 绑定 profile。

QoS Map 与 WRED：DSCP_TO_TC、TC_TO_QUEUE、PFC_PRIORITY_TO_PRIORITY_GROUP 分别处理不同映射。

Attribute 与 bulk 返回：sai_attribute_t 用 id 决定 value union 的有效成员；CREATE_ONLY 与 CREATE_AND_SET 区分可修改性。

Ethernet 字段与 L2

802.1Q 字段：基本 Ethernet 头 14B；VLAN tag 额外 4B，其中 TCI 为 PCP 3bit、DEI 1bit、VID 12bit。

FDB 学习与泛洪：以源 MAC 和广播域学习入口，以目的 MAC 查出口。

LACP 与 hash：LACP 使用 Slow Protocols EtherType 0x8809 协商成员状态；collecting/distributing 表示收集/发送资格。

FEC / PCS / SerDes：SerDes 负责串并转换和高速电信号，PCS 处理编码/块等逻辑，FEC 纠错。

IP / BGP / 邻居状态

LPM 算例：同一 VRF 中 10.0.0.0/8→A、10.1.0.0/16→B、10.1.2.0/24→C，目的 10.1.2.8 命中 C。

BGP 状态与消息：Idle→Connect/Active→OpenSent→OpenConfirm→Established；OPEN 协商参数，KEEPALIVE 维持会话，UPDATE 宣告/撤销路径，NOTIFICATION 报错。

邻居 NUD 状态：Linux 常见 INCOMPLETE、REACHABLE、STALE、DELAY、PROBE、FAILED。

MTU / 分片 / ICMP：IPv4 DF 阻止路由器分片时，过大报文需适当 ICMP 反馈；IPv6 路由器不分片，源端依据 Packet Too Big 调整。

VXLAN / EVPN 字段

VXLAN 报头：VXLAN 基本头 8B，包含 flags 与 24bit VNI；常见 UDP 目的端口 4789。

EVPN 路由类型：Type 1 为 Ethernet A-D，Type 2 宣告 MAC/IP，Type 3 为 Inclusive Multicast Ethernet Tag，Type 4 为 Ethernet Segment；Type 5 IP Prefix 来自扩展规范 RFC 9136。

RD / RT / VNI：RD 使不同租户重叠前缀的 VPN 路由可区分；RT 承载导入/导出策略；VNI 标识数据面虚拟网络。

封装 MTU 算例：内层 1500B IP+14B Ethernet，不含内层 FCS；外层 IPv4 20B+UDP 8B+VXLAN 8B，因此 underlay IP 包为 1550B。

QoS / ECN / PFC

DS field 与 ECN：IPv4 DS field 的高 6bit 是 DSCP，低 2bit 是 ECN：00 Not-ECT、10 ECT(0)、01 ECT(1)、11 CE。

动态阈值 α：简化模型 T=α×free_shared；α 固定时阈值随剩余空间线性变化。

PFC 帧与时间：PFC 使用 MAC Control EtherType 0x8808、opcode 0x0101，含优先级使能位和 8 个 pause time。

SP / DWRR / Shaping：SP 优先服务高优先级；DWRR 使用 deficit 与 quantum 按字节预算轮转，适应不同包长。

Linux RX / TX 路径

RX 典型调用点：驱动 poll 取完成描述符→构造 skb→napi_gro_receive→协议分发→ip_rcv/ipv6_rcv。

TX 典型调用点：输出路径经路由与邻居解析，再到 dev_queue_xmit/qdisc、驱动 ndo_start_xmit。

sk_buff 内存：skb->len 是总长，data_len 描述非线性数据长度，线性头长为 len−data_len；frags 可引用 page 数据。

NAPI 与 XDP：Native XDP 通常在驱动 RX、构造 skb 之前执行，但取决于驱动支持；generic XDP 路径不同。

switchdev / devlink 接口

FDB 通知：硬件学习/老化通过 SWITCHDEV_FDB_ADD_TO_BRIDGE / DEL_TO_BRIDGE 等对应版本接口通知 bridge；内核配置的 FDB 通过 TO_DEVICE 路径下发。

TC flower 卸载：Flower 用 key/mask 描述字段，action 可包括 drop、redirect、police 等。

Devlink 对象：devlink port 映射物理/逻辑端口，resource 显示设备资源，trap/trap group/policer 描述上送，health reporter 提供诊断和恢复。

Representor / e-switch：Representor 是虚拟端口的 Linux 控制/观测接口，实际 VF-to-VF 数据可由 NIC e-switch 硬件转发。

内存模型 / DMA / RCU

三种地址：CPU virtual、CPU physical 与 DMA bus address 不能互换。

Coherent / Streaming：Coherent allocation 为共享控制结构提供一致性，但仍可能需要写入顺序屏障。

RCU API 语义：读侧 rcu_read_lock/unlock 保护相应访问区间；更新侧先移除发布引用，再通过 synchronize_rcu 或 call_rcu 等等待既有读者结束后回收。

Cacheline 与 NUMA：多 CPU 更新同一 cacheline 上不同计数器也会产生 false sharing。

C / ABI / 报文解析

字节序：网络多字节字段使用 big-endian；ntohs/ntohl 与 htons/htonl 在边界转换。

对齐与长度：从不受信任缓冲读结构体可能遇到未对齐和 padding；先验证固定头、变长头再取 payload。

ABI 与符号：结构体大小、字段偏移、调用约定和动态符号共同组成兼容边界。

性能采样解释：perf 的 cycles/instructions/cache-misses 显示不同成本；热点函数可能只是调用汇聚点。

SONiC 进程与数据库

路由进程：bgpd 维护 BGP 邻接和路径；zebra 管理路由并向内核/FPM 导出；fpmsyncd 接收 FPM 写应用数据库；orchagent 按依赖创建 SAI 状态。

五类数据库：CONFIG_DB 保存配置输入，APPL_DB 保存应用产生状态，STATE_DB 提供运行/依赖状态，ASIC_DB 保存面向 ASIC 的对象表达，COUNTERS_DB 保存统计。

SAI Redis / syncd：SAI Redis 层可序列化对象操作；syncd 消费硬件方向操作并调用厂商 SAI。

统计采集：Counter 由 ASIC/SDK 暴露，经统计采集组件写入 COUNTERS_DB，采集周期带来时间差。

PCIe / 固件 / 端口初始化

PCIe 基础：BAR 描述 MMIO 资源，MSI-X 提供消息中断及向量，DMA 在主机与设备间传数据。

Mailbox / Doorbell：Mailbox 或 command queue 传递命令参数，doorbell 通知生产者位置，completion 返回 opcode/status/token。

Breakout 与 lane：一个前面板口拆分为多个 logical ports 时，lane 分组、速率、FEC 和模块能力必须一致。

光模块与 FEC 指标：模块 EEPROM/管理接口提供型号、温度与光功率等；PCS/FEC 统计来自链路逻辑。

重启机制与转发保留

Warm / Cold 区别：Cold 通常重置并重建较多设备状态；warm 是否保留 route、FDB、queue 和 link 取决于硬件/SDK。

BGP GR 与 BFD：BGP GR 通过能力与重启相关状态允许邻居暂时保留 stale 路由；End-of-RIB 标识相应更新阶段完成。

SDK 对象重建：已保留硬件对象与新进程中的 OID/引用需要重新对应。

Counter / Learning：重启可改变 counter 起点与 MAC aging 所有者。

CoPP / ACL / MACsec

Trap group / Policer：Hostif trap 选择上送原因，trap group 可绑定 CPU queue/policer。

ACL key / action：Ingress/Egress ACL stage 支持字段与动作可能不同，L3/L4 key、mask、priority、counter 与 packet action 独立配置。

MACsec 与 IPsec：MACsec 保护以太网链路帧，常见 EtherType 0x88E5，涉及 SecTAG、packet number、ICV 与 replay protection；SCI 可标识安全通道。

uRPF / 源验证：Strict uRPF 检查源地址反向最佳路径是否对应入口，loose 通常要求存在可接受源路由。

NCCL / 并行通信

Collective 数据量：AllGather 将每 rank M 字节汇集为 N×M；ReduceScatter 将各 rank 输入的规约结果分片；AllReduce 让所有 rank 得到规约结果。

Ring / Tree：Ring AllReduce 常分 ReduceScatter 与 AllGather 两阶段，每 rank 总传输约 2(N−1)M/N；Tree 减少小消息步数但有不同链路竞争。

Channel / Rail：Channel 是通信并行化资源，rail 是物理/逻辑 NIC 网络路径。

GPU→NIC 路径：GPUDirect RDMA 可使 NIC 对 GPU memory 进行直接访问，是否走 PCIe P2P 受平台拓扑和软件支持影响。

RoCEv2 报文与传输

外层报头：Ethernet 14B；可选 VLAN；IPv4 最小 20B 或 IPv6 40B；UDP 8B，目的通常 4791；随后 BTH 12B。

BTH / RETH / AETH：BTH 包含 opcode、P_Key、24bit destination QPN、24bit PSN 等。

RDMA Write 分段：RC Write First 可带 RETH，Middle 通常不重复 RETH，Last 结束该操作；Only 表示单包，带 immediate 的变体另含对应字段。

ICRC / CNP / Retry：ICRC 4B 与 Ethernet FCS 4B 作用不同，ICRC 处理按规则规范化的相关头字段。

网络性能公式

线上 PPS：pps=R/[8(L+20)]，L 含 MAC 帧与 FCS，20=8B preamble/SFD+12B IFG。

BDP 与排队：BDP=R×RTT/8；400Gb/s、10µs→500kB。

Incast 增长：ΔQ≈(arrival−service)×Δt。

Ring 时间模型：T≈2(N−1)α+2(N−1)M/(N·B)。

报文级测试技术

流量字段：用固定 VLAN、MAC、IP、L4 port 和 sequence payload 建立可识别流。

延迟测量：单向时延需要可比较时钟或同一测量域；RTT/2 假设对称，不适合直接推导非对称路径单向尾延迟。

ECMP 分布统计：少量 elephant flow 即使 hash 均匀也可能产生端口偏斜。

RDMA / NCCL 测量：RDMA perftest 与 nccl-tests 覆盖不同层：前者测试 verbs/端点传输，后者还受 GPU、collective 算法与 rank placement 影响。

Counter / Telemetry

Counter / Gauge：Counter 是累计事件，rate 需要同一来源两次差分并处理 reset/wrap；gauge 是某时刻状态。

队列指标：PG occupancy、shared occupancy、XOFF room、queue drops 与 ECN marked packets 描述不同资源/事件。

INT / sFlow：sFlow 通常采样报文并导出；INT 可随数据包携带逐跳 metadata，但封装位置、指令与导出模式依方案，并非统一在尾部追加字段。

PHY 与拥塞区分：CRC/uncorrectable FEC 反映链路错误，buffer discard 表示资源/策略相关丢弃，PFC TX/RX 是暂停收发，retry 是端点传输反应。

Linux / NOS 命令解释

ip / bridge：ip -d link 显示设备/封装；ip route show table all 查看多表；ip neigh 显示 NUD；bridge fdb show 显示 MAC/VLAN/port 与 offload 信息。

ethtool / tc：ethtool -S 的字段依驱动；-k 显示卸载特性；tc -s qdisc 显示主机调度统计，tc -s filter 查看规则计数。

devlink / 日志：devlink dev/port/resource/health show 分别执行；journalctl -k 查看内核日志。

FRR / RDMA：vtysh -c "show bgp summary" 看会话；具体前缀需再查 BGP/RIB/FIB。

故障特征定位

MTU 黑洞：小包通、大包超时且链路错误少，优先检查每跳 MTU、DF 与 ICMP/PTB 过滤。

ECMP 热点：总利用率低但某出口满，检查五元组熵、隧道内层 hash、elephant 分布与成员有效状态。

PFC 传播：从接收端拥塞出口向上游逐跳比较 pause TX/RX 和占用，定位持续阻塞的起点。

软硬 FIB 分叉：RIB 有前缀、ASIC 无条目时检查资源错误、下一跳/neighbor 就绪和下发路径；ASIC 有条目但不通，再检查 rewrite、ACL、queue 与出口。

关键字段与单位

ID 宽度：VLAN VID 12bit；VXLAN VNI 24bit；RoCE QPN/PSN 24bit；DSCP 6bit；ECN 2bit；PCP 3bit。

时间与字节：PFC quantum=512 bit-times；IPv4 IHL 以 4B 为单位；TCP data offset 也以 4B 为单位；UDP length 包含 UDP 头。

协议标识：EtherType IPv4=0x0800、ARP=0x0806、IPv6=0x86DD；IP protocol TCP=6、UDP=17；BGP TCP 179、VXLAN UDP 4789、RoCEv2 UDP 4791。

Queue 层次：SDK command queue、NIC WQ/CQ、Linux qdisc、ASIC ingress PG、egress queue 分属不同层。
