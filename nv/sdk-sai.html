Route 是 keyed entry

Routes are keyed entries

sai_route_entry_t 的键为 switch_id、vr_id、destination；创建路由不返回新的 route OID。

sai_route_entry_t is keyed by switch_id, vr_id and destination; creating a route does not return a new route OID.

SAI_ROUTE_ENTRY_ATTR_NEXT_HOP_ID 指向下一跳、组，或直接连接场景的 router interface；IP2ME 可指向 CPU port。

SAI_ROUTE_ENTRY_ATTR_NEXT_HOP_ID targets a next hop/group, a router interface for connected routes, or CPU port for IP2ME.

Buffer 对象关系

Buffer object graph

Buffer pool 表示容量及 ingress/egress 类型；profile 引用 pool 并定义预留与阈值；ingress priority group 或 queue 绑定 profile。

Pools describe capacity and ingress/egress type; profiles reference pools and define reservations/thresholds; ingress priority groups or queues bind profiles.

SAI 将这些层拆成独立对象，不能把 pool size、PG headroom 与 egress queue limit 当成同一个数字。

These are separate SAI objects: pool size, PG headroom and egress queue limits are not one number.

QoS Map 与 WRED

QoS maps & WRED

DSCP_TO_TC、TC_TO_QUEUE、PFC_PRIORITY_TO_PRIORITY_GROUP 分别处理不同映射。

DSCP_TO_TC, TC_TO_QUEUE and PFC_PRIORITY_TO_PRIORITY_GROUP represent distinct mappings.

WRED profile 提供颜色相关阈值与概率，ECN mark mode 独立指定标记行为，queue 再绑定 WRED。没有通用“RoCE 必须 Q3”的 API 规定。

WRED profiles expose color-related thresholds/probabilities and ECN marking mode; queues bind profiles. SAI does not universally require RoCE queue 3.

Attribute 与 bulk 返回

Attributes & bulk results

sai_attribute_t 用 id 决定 value union 的有效成员；CREATE_ONLY 与 CREATE_AND_SET 区分可修改性。

Attribute IDs select the valid value-union member; CREATE_ONLY and CREATE_AND_SET define mutability.

Bulk 返回还包含逐对象状态数组，整体失败不等于所有对象未创建；枚举/API 存在也不证明设备支持所有属性值。

Bulk calls return per-object statuses: overall failure does not mean nothing was created. API/enum existence does not prove support for every value.

部分失败的事务日志

Journaling partial failures

日志条目至少包含 operation_id、epoch、object_key、action、previous_state、result。批量创建的结果逐项记录，补偿按依赖逆序执行；共享对象通过引用而非盲目删除回收。若错误返回为资源满，先终止依赖它的新操作；若为 timeout，先查询或 reconcile，防止同一对象重复创建。

Journal operation_id, epoch, object_key, action, previous_state and result. Record bulk outcomes per item and compensate in reverse dependency order. Reclaim shared objects through references. Exhaustion should stop dependent creation; timeouts require querying or reconciliation to prevent duplicate objects.
