MTU 黑洞

MTU black hole

小包通、大包超时且链路错误少，优先检查每跳 MTU、DF 与 ICMP/PTB 过滤。

Small packets work but large ones time out with few link errors: inspect hop MTUs, DF and ICMP/PTB filtering.

隧道下增加封装开销更易暴露；通过逐步增大受控报文和比较封装前后长度定位，不把它误判为随机丢包。

Tunnel overhead exposes this more readily. Sweep controlled sizes and compare inner/outer lengths rather than calling it random loss.

ECMP 热点

ECMP hotspots

总利用率低但某出口满，检查五元组熵、隧道内层 hash、elephant 分布与成员有效状态。

Low aggregate use with one full egress suggests hash entropy, inner-header hashing, elephant distribution or member state.

改变源端口后热点移动可提供 hash 相关证据；单流受单路径限制不必然是交换性能不足。

Moving hotspots after source-port changes supports a hash explanation. Single-flow path limits do not imply insufficient switch capacity.

PFC 传播

PFC propagation

从接收端拥塞出口向上游逐跳比较 pause TX/RX 和占用，定位持续阻塞的起点。

Trace pause TX/RX and occupancy upstream from congested egress to the persistent origin.

PFC 属于优先级范围，可阻塞同优先级无关流；deadlock 需要依赖环等条件，不等于任意长 pause。

Priority-scoped PFC can block unrelated same-priority flows. Deadlock requires conditions such as dependency cycles, not merely a long pause.

软硬 FIB 分叉

Software/hardware FIB divergence

RIB 有前缀、ASIC 无条目时检查资源错误、下一跳/neighbor 就绪和下发路径；ASIC 有条目但不通，再检查 rewrite、ACL、queue 与出口。

For RIB presence but missing ASIC entry, inspect resources, next-hop/neighbor readiness and programming path.

把路由存在和邻接存在分开验证，可快速缩小黑洞范围。

For installed entries without traffic, inspect rewrite, ACLs, queues and egress. Separate route from adjacency existence.

故障树：入口有包出口无包

Fault tree: ingress without egress

先确认统计窗口与报文标识一致；然后按 VLAN/classification→ACL→FDB/FIB→neighbor/rewrite→queue→egress link 分叉。每一步要求一个正向证据和一个排除证据，例如 ACL counter 命中但 drop action 未触发。不要以“配置看着正常”跳过硬件表或资源检查。

Align windows and packet identity, then branch through VLAN/classification→ACL→FDB/FIB→neighbor/rewrite→queue→egress link. Require positive and exclusion evidence at each stage, such as rule hits without a drop action. Do not skip hardware tables/resources because configuration looks correct.
