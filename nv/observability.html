Counter / Gauge

Counter / gauge

Counter 是累计事件，rate 需要同一来源两次差分并处理 reset/wrap；gauge 是某时刻状态。

Counters accumulate events and need reset/wrap-aware deltas; gauges describe state.

Watermark 是区间峰值，不等同当前 occupancy。清零读与周期采样并用可能导致多个采集者相互干扰。

Watermarks are interval peaks, not current occupancy. Clear-on-read plus multiple collectors can cause interference.

队列指标

Queue metrics

PG occupancy、shared occupancy、XOFF room、queue drops 与 ECN marked packets 描述不同资源/事件。

PG/shared/XOFF occupancy, queue drops and ECN marks describe different resources/events.

先明确 ingress/egress 和单位，再相关分析；不能用 host qdisc 的 backlog 代替交换机 headroom。

Identify ingress/egress and units first. Host qdisc backlog cannot substitute for switch headroom.

INT / sFlow

INT / sFlow

sFlow 通常采样报文并导出；INT 可随数据包携带逐跳 metadata，但封装位置、指令与导出模式依方案，并非统一在尾部追加字段。

sFlow generally samples/exports packets; INT may carry hop metadata, but placement/instructions/export depend on the scheme rather than universally appending a trailer.

新增 metadata 会增加 MTU 和处理成本，采样也会漏掉短流。

Metadata adds MTU/processing cost; sampling can miss short flows.

PHY 与拥塞区分

PHY vs congestion

CRC/uncorrectable FEC 反映链路错误，buffer discard 表示资源/策略相关丢弃，PFC TX/RX 是暂停收发，retry 是端点传输反应。

CRC/uncorrectable FEC indicates link errors; buffer discards indicate resource/policy drops; PFC TX/RX counts pauses; retries reflect endpoint recovery.

多个计数同时增长可能有因果链，但名称相似不代表同一故障层。

Correlated counters may form a causal chain but are not the same fault layer.

Example: counter deltas

10 秒窗口入口 1,000,000 包、出口 990,000 包不立即等于丢了 10,000：检查窗口边界、队列残留、复制、trap、不同统计口径与 counter reset。先将入/出/丢弃/上送统一到同一测量域，再进行守恒分析；多播场景出口总包数合法地大于入口。

1,000,000 ingress and 990,000 egress packets over 10s does not immediately prove 10,000 losses. Check boundaries, queued packets, replication, traps, semantics and resets. Align ingress/egress/drop/punt domains before conservation analysis; multicast can legitimately produce more egress packets.
