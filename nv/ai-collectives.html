Collective 数据量

Collective data volumes

AllGather 将每 rank M 字节汇集为 N×M；ReduceScatter 将各 rank 输入的规约结果分片；AllReduce 让所有 rank 得到规约结果。

AllGather combines M bytes per rank into N×M; ReduceScatter partitions reduced data; AllReduce returns the reduction everywhere.

不同 API 对 count 的定义应按接口核对，不能把所有测试的 size 都当每 rank 网络发送量。

Check each API's count semantics: benchmark size is not universally bytes sent per rank.

Ring / Tree

Ring / tree

Ring AllReduce 常分 ReduceScatter 与 AllGather 两阶段，每 rank 总传输约 2(N−1)M/N；Tree 减少小消息步数但有不同链路竞争。

Ring AllReduce commonly has ReduceScatter and AllGather phases with about 2(N−1)M/N transfer per rank.

NCCL 根据规模/拓扑/算法支持选择实现，不等于固定使用一个 Ring。

Trees reduce small-message steps with different contention. NCCL selection depends on scale/topology/support, not one fixed ring.

Channel / Rail

Channel / rail

Channel 是通信并行化资源，rail 是物理/逻辑 NIC 网络路径。

Channels parallelize communication; rails represent NIC/network paths.

特定 Spectrum-X 插件按 HCA rail 组织流，但不能推导所有 NCCL channel 与 rail 永远 1:1；跨 rail 与跨 Spine 取决于拓扑和配置。

Specific Spectrum-X plugins organize flows by HCA rail, but this does not make every NCCL channel permanently 1:1 with a rail. Cross-rail/spine behavior depends on topology/configuration.

GPU→NIC 路径

GPU→NIC path

GPUDirect RDMA 可使 NIC 对 GPU memory 进行直接访问，是否走 PCIe P2P 受平台拓扑和软件支持影响。

GPUDirect RDMA can allow NIC access to GPU memory; PCIe P2P depends on platform topology/software.

GPU/NIC affinity、PCIe 带宽与 NUMA 都可能限制通信；NIC 线速不等于 collective 的有效带宽。

GPU/NIC affinity, PCIe bandwidth and NUMA can limit communication. NIC line rate is not collective effective bandwidth.

实例：慢 rank 放大

Example: slow-rank amplification

若 63 个 rank 每阶段 8ms 完成、1 个需 12ms，同步阶段可能被 12ms 者限制，而其他 GPU 在等待。总网络利用率不高不能排除问题。比较 rank/NIC/NUMA 映射，交换慢 rank 的放置再重测；若慢点跟随物理位置，优先查主机和路径，若跟随任务，查负载不均。

If 63 ranks finish a phase in 8ms and one takes 12ms, synchronization may be limited by the 12ms rank while others wait. Low utilization proves little. Swap placement: if slowness follows hardware, inspect hosts/paths; if it follows work, inspect imbalance.
