QoS / 缓冲 / 负载均衡

QoS / buffers / load balancing

原理与实现路径

Mechanisms & implementation path

Arrival > service → queue growth → ECN → endpoint feedback
                                ↘ PFC if configured → link pause

分类与调度

Classification & scheduling

DSCP/PCP trust → priority/TC → queue；remark、SP/WRR/DWRR、ETS、shaping/policing、token bucket；防止低优先级饥饿。

DSCP/PCP trust → priority/TC → queue. Remarking, SP/WRR/DWRR, ETS, shaping/policing and token buckets. Prevent lower-priority starvation.

入口 trust 决定采用外部 DSCP/PCP 还是重分类；内部 TC 决定队列，出口 remark 决定下游看到的标记。逐跳检查这三层映射，否则相同 DSCP 可能在不同设备落入不同拥塞域。

Ingress trust selects external DSCP/PCP or reclassification; internal TC selects queues; egress remarking determines downstream markings. Verify all three mappings hop by hop: the same DSCP can otherwise enter different congestion domains.

缓冲

Buffers

Ingress/egress pool、shared/reserved、headroom、动态阈值、cell 粒度；区分端口与全局共享资源，检查队列水位和丢包原因。

Ingress/egress pools, shared/reserved buffers, headroom, dynamic thresholds and cell granularity. Distinguish per-port from globally shared resources; inspect watermarks and drop reasons.

共享池提高利用率，但一个突发端口可能挤占其他端口空间。Reserved 与 headroom 的语义依芯片；阈值配置必须先换算到实际 cell 粒度，再验证多个 lossless 优先级同时触发时总预算是否足够。

Shared pools improve utilization, but bursts on one port can consume space needed elsewhere. Reserved/headroom semantics are chip-specific. Convert thresholds to actual cell granularity and validate simultaneous lossless priorities against the total budget.

拥塞控制

Congestion control

ECN/WRED 阈值与概率影响吞吐/时延；PFC 可能引发 pause storm、deadlock、HoL 和拥塞扩散。Watchdog 需定义隔离、恢复和副作用。

ECN/WRED thresholds and probabilities affect throughput/latency. PFC can cause pause storms, deadlock, HoL and congestion spreading. Define watchdog isolation, recovery and side effects.

PFC 是逐链路暂停，不知道最终流的拥塞根因，暂停可能向上游扩散。ECN 依赖反馈回路，标记后发送者不会瞬间降速；设计队列阈值时应为反馈期间持续到达的数据留空间。

PFC pauses individual links without identifying end-flow congestion causes, so pauses can spread upstream. ECN uses a feedback loop; senders do not slow instantly after marking. Queue thresholds must accommodate arrivals during feedback delay.

路径选择

Path selection

ECMP hash/seed、内层字段、resilient hash、flowlet/adaptive routing；关注重排与端点能力。用 incast、微突发、多跳和冷热流验证公平性。

ECMP hashes/seeds, inner fields, resilient hashing and flowlet/adaptive routing. Check reordering and endpoint support. Test fairness with incast, microbursts, multiple hops and mixed flow sizes.

Flowlet 只在足够空闲间隔后换路以降低重排风险，间隔需覆盖路径时延差。Adaptive routing 还需考虑反馈新鲜度与振荡；测试时既测总吞吐，也测重排、单流公平性及拥塞恢复。

Flowlet switching changes paths after sufficient idle gaps to reduce reordering; the gap must account for path-delay differences. Adaptive routing must consider feedback freshness and oscillation. Measure reordering, per-flow fairness and recovery as well as throughput.

队列增长模型

Queue growth model

对某出口，短时间内 ΔQ≈(Σarrival−service)×Δt；速率单位应统一为 B/s。四个 100Gb/s 发送者同时流向一个 100Gb/s 出口，持续 10µs，理想积压约 (400−100)Gb/s×10µs/8=375kB，尚未计其他突发与实现开销。平均利用率低也可能反复出现这种瞬时过载。

For one egress, ΔQ≈(Σarrival−service)×Δt, using B/s. Four 100Gb/s senders targeting one 100Gb/s egress for 10µs ideally build about 375kB, before other bursts/overheads. Low average utilization can coexist with repeated instantaneous overload.

阈值联合设计

Coordinated thresholds

将正常队列区、ECN 标记区、PFC 触发区与实际溢出边界画在同一单位轴上，但阈值可能位于不同 ingress/egress 资源，不能直接比较数值大小。先核对资源对应关系，再根据反馈延迟与最大突发调节；每轮仅改一个变量，检查吞吐、尾延迟、标记率和 pause 时长。

Map normal occupancy, ECN marking, PFC triggering and overflow in consistent units, but thresholds may belong to different ingress/egress resources and cannot always be directly ordered. Establish resource relationships first, then tune for feedback delay/bursts one variable at a time while measuring throughput, tails, marking and pause duration.

诊断与取舍

Diagnosis & trade-offs

ECN 过早可能牺牲利用率，过晚可能导致溢出或频繁 PFC；SP 保护高优先级也可能饿死其他队列。用单流、incast、混合 RTT、不同包长和故障降速构成矩阵。不要仅以“PFC 包数量下降”作为改进结论，它也可能表示本应无损的队列开始直接丢包。

Early ECN may reduce utilization; late marking can overflow buffers or invoke PFC frequently. SP can protect one class while starving others. Test single flows, incast, mixed RTTs, packet sizes and degraded links. Fewer PFC packets alone may indicate drops rather than improvement.
