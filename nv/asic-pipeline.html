Parser / Metadata

Parser / metadata

Parser 根据 EtherType、IP protocol、UDP 端口等识别层级，提取 key 与内部 metadata。

Parsers identify layers through EtherType, IP protocol and UDP ports, extracting keys and metadata.

IPv6 扩展头、叠加 VLAN、嵌套隧道可能超过解析深度；动作依赖字段何时可用，不能任意把规则放到任何 stage。

IPv6 extensions, stacked VLANs and nested tunnels may exceed parse depth. Action placement depends on field availability; rules cannot occupy arbitrary stages.

TCAM 匹配语义

TCAM match semantics

ternary 位可为 0、1、don't-care，结合优先级决定重叠规则命中。

Ternary bits encode 0, 1 or don't-care; priority resolves overlaps.

一个端口范围可能展开成若干 mask 规则；增加 key 宽度可能改变 slice 消耗。并发查找、stage 数与周期数属于具体芯片实现，不应写成通用“1 周期”。

Port ranges may expand into multiple masks, and wider keys may consume additional slices. Lookup concurrency, stage counts and cycles are chip-specific, not universally one cycle.

Rewrite 与校验和

Rewrite & checksums

L3 转发更新 TTL/Hop Limit 和二层地址；IPv4 还需更新头校验和，IPv6 没有该头校验和。

L3 forwarding updates TTL/Hop Limit and L2 addresses.

封装/解封装影响长度和外层 checksum。修改后的 Ethernet 帧由出口 MAC 生成 FCS，RoCE ICRC 则是另一层校验。

IPv4 additionally updates its header checksum; IPv6 has none. Encapsulation affects lengths and outer checksums. Egress MAC generates Ethernet FCS; RoCE ICRC is a separate integrity layer.

TM / VOQ / 调度

TM / VOQ / scheduling

Buffer 保存报文或 cells，descriptor 记录队列与元信息，scheduler 决定何时服务哪个队列。

Buffers hold packets/cells, descriptors track queue metadata, and schedulers choose service.

VOQ 按目的出口等维度分队列以减轻 HoL；共享缓冲描述空间分配，VOQ 描述排队组织，两者不是互斥概念。

VOQs separate traffic by destination egress or related dimensions to reduce HoL. Shared buffering describes memory allocation; VOQ describes queue organization, so they are not mutually exclusive.

算例：回流吞吐上限

Example: recirculation throughput bound

假设某内部路径可处理 P 次包遍历/s，比例 f 的报文需要额外一次遍历，则平均每个外部包消耗 1+f 次，理想上限约 P/(1+f)。f=1 时该资源对应外部 pps 上限减半。真实 ASIC 可能有独立回流通道或其他先饱和资源，此式只用于识别待验证瓶颈，不能代替芯片规格。

If an internal resource handles P traversals/s and fraction f needs one extra pass, average cost is 1+f and the ideal external bound is P/(1+f). At f=1 that resource permits half the external pps. Dedicated recirculation paths and other bottlenecks may change actual hardware behavior; use this to identify hypotheses, not replace specifications.
