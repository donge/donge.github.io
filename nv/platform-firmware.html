PCIe 基础

PCIe basics

BAR 描述 MMIO 资源，MSI-X 提供消息中断及向量，DMA 在主机与设备间传数据。

BARs expose MMIO, MSI-X provides interrupt vectors and DMA transfers data.

PCIe lane 速率不等于有效 payload 带宽，TLP/DLLP 和编码有开销；ACS/IOMMU 等设置还可能影响 P2P 路径。

Lane bit rate differs from payload bandwidth due to TLP/DLLP/coding overhead. ACS/IOMMU and topology can also affect P2P paths.

Mailbox / Doorbell

Mailbox / doorbell

Mailbox 或 command queue 传递命令参数，doorbell 通知生产者位置，completion 返回 opcode/status/token。

Mailboxes/queues carry parameters, doorbells publish producer positions and completions return opcode/status/token.

固件 reset 后旧 token 可能失效；寄存器访问正常并不证明命令引擎或数据 DMA 正常。

Resets can invalidate old tokens. Working register access does not prove command-engine or data-DMA health.

Breakout 与 lane

Breakout & lanes

一个前面板口拆分为多个 logical ports 时，lane 分组、速率、FEC 和模块能力必须一致。

Breakout requires consistent lane grouping, speed, FEC and module capability.

Port ID 不应直接等同 lane index；改变 breakout 可能重建端口及绑定其上的 VLAN/LAG/QoS 对象。

Port IDs are not lane indices. Changing breakout can reconstruct ports and their VLAN/LAG/QoS bindings.

光模块与 FEC 指标

Optics & FEC metrics

模块 EEPROM/管理接口提供型号、温度与光功率等；PCS/FEC 统计来自链路逻辑。

Module management exposes identity, temperature and optical power; PCS/FEC counters come from link logic.

TX 光功率正常但 RX 弱可能是介质/连接问题；pre-FEC 与 post-FEC 指标不可直接混算成同一种丢包率。

Healthy TX with weak RX may indicate media/connectors. Pre/post-FEC metrics are not interchangeable packet-loss rates.

复位域与依赖矩阵

Reset-domain dependency matrix

表格行列列出 CPU、PCIe function、firmware、ASIC core、SerDes 与模块，逐项记录某种 reset 会影响哪些域、哪些表保留、DMA 是否停止、端口是否 flap。所有恢复设计必须以实测 reset 行为为基础；“软重启”名称无法推出故障范围。

Matrix CPU, PCIe function, firmware, ASIC core, SerDes and modules against resets; record affected domains, retained tables, stopped DMA and port flaps. Base recovery on measured reset behavior, not names such as soft reboot.
