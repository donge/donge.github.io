ID 宽度

ID widths

VLAN VID 12bit；VXLAN VNI 24bit；RoCE QPN/PSN 24bit；DSCP 6bit；ECN 2bit；PCP 3bit。

VLAN VID 12 bits; VXLAN VNI 24; RoCE QPN/PSN 24; DSCP 6; ECN 2; PCP 3.

字段可编码数量与设备实际表容量是两回事，24bit VNI 不保证能创建 1600 万个隧道。

Encoding space differs from hardware capacity: 24-bit VNI does not guarantee 16 million instantiated tunnels.

时间与字节

Time & bytes

PFC quantum=512 bit-times；IPv4 IHL 以 4B 为单位；TCP data offset 也以 4B 为单位；UDP length 包含 UDP 头。

PFC quanta are 512 bit-times; IPv4 IHL and TCP data offset count 4B words; UDP length includes its header.

Counter 的 bytes 是否含 L2/FCS/preamble 由测量点与设备定义，不能默认一样。

Counter bytes may or may not include L2/FCS/preamble depending on the measurement point/device.

协议标识

Protocol identifiers

EtherType IPv4=0x0800、ARP=0x0806、IPv6=0x86DD；IP protocol TCP=6、UDP=17；BGP TCP 179、VXLAN UDP 4789、RoCEv2 UDP 4791。

EtherTypes: IPv4 0x0800, ARP 0x0806, IPv6 0x86DD; IP protocols TCP 6, UDP 17; ports BGP TCP179, VXLAN UDP4789, RoCEv2 UDP4791.

端口识别只是分类线索，不证明 payload 有效。

Identifiers aid classification but do not validate payloads.

Queue 层次

Queue layers

SDK command queue、NIC WQ/CQ、Linux qdisc、ASIC ingress PG、egress queue 分属不同层。

SDK queues, NIC WQ/CQ, Linux qdisc, ASIC ingress PG and egress queues belong to different layers.

WQ 放工作请求，CQ 放完成，PG 管理入口缓存分类，egress queue 等待调度；增加一种 queue depth 不会自动扩大其他层。

WQs hold work, CQs completions, PGs ingress buffer classification and egress queues scheduled traffic. Increasing one depth does not enlarge the others.

易混实例

Common confusion example

“队列满”可能指 SDK 命令队列、NIC WQ/CQ、Linux qdisc、ASIC buffer 或软件事件队列；它们的生产者、消费者、单位和恢复动作都不同。诊断输出必须写清 queue type、owner、capacity unit、drop/backpressure 行为；否则调整某个 queue depth 很可能作用在错误层。

A full queue may mean SDK commands, NIC WQ/CQ, Linux qdisc, ASIC buffering or software events. Producers, consumers, units and recovery differ. Report type, owner, capacity units and drop/backpressure behavior before tuning a potentially unrelated depth.
