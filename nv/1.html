软件架构与状态一致性

三平面：管理面负责配置、身份、升级和遥测；控制面负责协议与路由计算；数据面负责查表、修改、排队和发送。明确 CPU、ASIC 与固件的职责。

控制链：配置/协议 → 编排 → SAI 或 SDK → ASIC；Linux switchdev 是另一种卸载路径，不是所有系统必经的串联层。

一致性：区分期望态、软件已应用态与硬件实际态；使用 generation、幂等更新、事件重放、依赖图和 reconcile 处理重复、乱序、漂移与重启。

接口与取舍：定义状态所有者、API 合约、超时/取消、错误语义、有界队列与背压；权衡可移植性/芯片能力、吞吐/延迟、隔离/利用率。

容量与性能预算

负载输入：端点/GPU 数、并发作业、流数、消息尺寸、突发持续时间、东西向流量、租户隔离、拓扑亲和性。

资源维度：端口/速率、Tb/s 与 pps、MAC/路由/邻居/ECMP/ACL/隧道数量、队列/缓冲、CPU/内存、表项编程速率与遥测开销。

共享限制：SRAM/TCAM、IPv6 宽表项、ACL key/action、计数器可能争用资源；各特性独立最大值不能相加。分析最坏组合、余量和降级顺序。

验收指标：明确帧长/封装/单双向口径；测 p50/p99/p99.9 延迟、丢包、收敛、恢复及训练 step time；固定规模、故障条件、容差与基线。

ASIC 转发流水线

报文路径：MAC → parser → match/classify → L2/L3/ACL → action/rewrite → buffer/MMU → scheduler → egress；实际阶段顺序与动作组合依芯片。

查表与资源：Exact match、LPM、TCAM、优先级/mask、key width、hash 碰撞；关注 stage 资源、隧道、镜像、复制、计数、drop/trap 的组合限制。

性能边界：最小帧 pps、recirculation、内部 fabric 与复制带宽可能先饱和；cut-through/store-and-forward、共享缓冲/VOQ 和 HoL 决定时延与拥塞行为。

软件可控性：寄存器/表访问、DMA 命令、异步完成、影子表、原子更新、资源耗尽、错误码及勘误；P4/可编程 parser 能力按芯片确认。

SDK / SAI 接口

抽象边界 [S4]：SAI 为 forwarding element 提供厂商无关 API；SDK/adapter 落实芯片能力。统一 API 不代表所有芯片资源、原子性与语义相同。

对象依赖：Port、VLAN/bridge、router interface、neighbor/next hop、next-hop group、route、ACL table/entry/counter；按 API 依赖建立、逆序释放。

生命周期与并发：Create/set/get/remove、OID 映射、引用计数、能力查询、create-only 属性、版本兼容；明确线程安全、锁顺序、回调上下文和事件背压。

失败处理：批量 API 未必原子：预校验 → 资源预留 → 依赖排序 → 提交 → 验证；部分失败需补偿/回滚、幂等重试与软硬对账，禁止静默降级。

Ethernet / 链路 / L2

物理与端口：SerDes、NRZ/PAM4、PCS/PMA、协商、link training、FEC、BER；lane/logical/front-panel 映射、breakout、admin/oper、热插拔与 flap。

帧与链路预算：DA/SA、802.1Q、EtherType、FCS、MTU/Jumbo；线速计入 preamble/SFD 和 IFG。检查 DAC/AOC/光模块、光功率、温度及 FEC 错误。

二层交换：MAC 学习/老化/移动、FDB、VLAN/PVID、tagged/untagged、QinQ、未知单播/广播/多播泛洪；表满行为与风暴抑制。

环路与聚合：STP/RSTP/MSTP、BPDU guard、LAG/LACP、哈希偏斜、MLAG split-brain/peer-link；用 LLDP 与镜像定位。Link up 不等于业务可达。

IP / 路由 / 下一跳

转发基础：IPv4/IPv6、TTL/Hop Limit、LPM、下一跳/rewrite、ICMP；ARP/ND/DAD、邻居容量、PMTUD/黑洞、IPv6 扩展头与不由路由器分片。

状态链：协议选路 → RIB → FIB → 下一跳组 → ASIC；递归解析、邻接未就绪、撤销顺序、批量编程、黑洞/环路窗口。

控制协议：BGP eBGP/iBGP、属性/策略、RR、MP-BGP、GR、max-prefix；OSPF/IS-IS、LSDB/SPF；BFD 定时器与硬件卸载，关注 route churn 和背压。

转发分支：VRF、PBR、ECMP/UCMP、resilient hashing、uRPF、内层 hash 熵；IGMP/MLD、PIM、多播复制按场景深入。

Clos / VXLAN / EVPN

Fabric 拓扑：Leaf–Spine、Clos/fat-tree、多级 Clos、ToR/EoR、双归属；radix、跳数、双截带宽、超售、故障域、布线与扩容。

Underlay：L3 ECMP、地址/路由规划、BGP/IGP、汇总、故障隔离与 drain；重哈希引起重排，策略可能造成路径不对称。

Overlay [S5/S6]：VXLAN：VTEP/VNI、L2 over UDP/IP、封解装与 MTU；EVPN：MAC/IP 可达性、RT/RD、L2/L3VNI、IRB。基础 EVPN RFC 为 MPLS，VXLAN/IRB 需配套规范。

高级行为：MAC mobility、ARP/ND suppression、BUM、head-end replication、multihoming、DF election、split-horizon；验证 VTEP 故障、迁移和 underlay 未就绪。

QoS / 缓冲 / 负载均衡

分类与调度：DSCP/PCP trust → priority/TC → queue；remark、SP/WRR/DWRR、ETS、shaping/policing、token bucket；防止低优先级饥饿。

缓冲：Ingress/egress pool、shared/reserved、headroom、动态阈值、cell 粒度；区分端口与全局共享资源，检查队列水位和丢包原因。

拥塞控制：ECN/WRED 阈值与概率影响吞吐/时延；PFC 可能引发 pause storm、deadlock、HoL 和拥塞扩散。Watchdog 需定义隔离、恢复和副作用。

路径选择：ECMP hash/seed、内层字段、resilient hash、flowlet/adaptive routing；关注重排与端点能力。用 incast、微突发、多跳和冷热流验证公平性。

Linux 网络数据路径

RX / TX：RX：DMA ring → IRQ/NAPI → skb/GRO → 协议栈/bridge/route；TX：socket/forward → route/neighbor → qdisc → ndo_start_xmit → DMA/completion。

核心对象：net_device、sk_buff、page/page_pool、socket/netns；skb 线性/非线性、headroom、clone/refcount、GSO/TSO/checksum offload。

调度与接口：softirq、NAPI budget、IRQ affinity、RSS/RPS/XPS、NUMA/cache；rtnetlink/netlink、notifier、ethtool；处理 dump 与通知的竞态和重同步。

卸载边界：ASIC 数据转发通常不逐包经过 Linux。区分硬件快路径、CPU trap、主机栈与软件 fallback；抓不到包不证明没有转发。

switchdev / devlink / TC

switchdev [S1]：将内核控制的转发平面卸载到硬件；关注 bridge/FDB/VLAN/FIB 同步、offload 失败、学习/老化事件以及重复转发。

devlink [S2]：设备/ASIC 级管理：资源、参数、端口、health、traps、reload；各驱动支持范围不同，查询能力后再设计依赖。

TC / BPF：tc flower match/action、硬件统计、skip_sw/skip_hw；eBPF/XDP 主机快路径与观测不等于 ASIC 可卸载，需验证动作组合与 fallback。

相邻机制：DSA、representor、SR-IOV/e-switch、vDPA、DPDK/AF_XDP 各有场景；检查 reset、锁、资源回收、extack 和内核/固件兼容。

OS / 并发 / 内存

执行与同步：进程/线程、调度、IPC、event loop、workqueue/timer；mutex/spinlock/rwlock、atomic、RCU、completion；锁顺序、优先级反转与中断不可睡眠。

内存语义：虚拟内存、page/slab、栈/堆、碎片/OOM、对齐/字节序；cache coherence 不等于内存顺序；barrier、MMIO、DMA 有独立约束。

DMA 与生命周期：Coherent/streaming mapping、IOMMU、cache 同步、ring 所有权；引用计数、延迟释放、取消/回调竞争、UAF/double-free、reset 中未完成 DMA。

系统稳定性：FD/线程/内存泄漏、cgroup、watchdog、磁盘满、时钟跳变；有界队列、背压、重试退避，防止故障放大。

编码 / 构建 / 调试

编程基础：C/C++ 指针、位运算、结构布局、所有权、RAII、UB/ABI；Python 测试和自动化；Shell 系统诊断。状态机与错误路径应可测试。

构建与交付：交叉编译、toolchain/sysroot、Make/CMake、静态/动态链接、符号、依赖锁定、可复现构建、镜像裁剪与版本矩阵。

诊断工具：gdb/core、perf、ftrace/trace-cmd、strace、bpftrace；KASAN/KCSAN/lockdep、ASan/UBSan；评估工具对负载和时序的扰动。

质量检查：正常/异常/并发/重启路径；输入与溢出、锁范围、清理、兼容；静态检查、单元/集成/硬件回归、可追溯构件和故障复现。

NOS / SONiC

系统组成：管理/配置、协议进程、状态库、编排、平台服务、遥测、升级；进程隔离不等于状态隔离，必须明确所有权与恢复顺序。

SONiC 路径 [S3]：APPL_DB → orchagent → SAI 对象 → ASIC_DB/syncd → SAI 实现；CONFIG_DB、STATE_DB、COUNTERS_DB 用途不同，具体路径按版本源码核对。

协议与服务：FRR 等路由栈到内核/编排同步；端口/VLAN/邻居/路由依赖；容器生命周期、watchdog、平台抽象、schema 迁移、就绪检查与配额。

异常恢复：DB 断连、事件丢失、进程重启、SDK 卡死、对象孤儿、软硬漂移；提供 reconcile 和诊断快照。数据库记录不等于硬件已成功应用。

平台 / 固件 / Bring-up

启动与接口：ROM/bootloader → kernel/rootfs → driver → firmware/SDK → NOS；PCIe/BAR/MSI-X、DMA/IOMMU、I2C/MDIO/SPI、CPLD/FPGA/BMC。

平台管理：风扇、PSU、温度/电压、EEPROM、光模块与热插拔；明确驱动/daemon/NOS 边界，设计温控、降频、关机与带外诊断。

固件合约：Mailbox/command queue、ABI/版本、超时/重试、异步事件、reset 域、资源重建和 crash dump；维护驱动/固件/SDK 兼容矩阵。

首片验证：仿真/emulation → 首片 → 板卡 → 系统；先最小收发/环回，再链路/FEC、查表、流量和热/电源；记录黄金配置、限制与勘误绕过。

HA / 升级 / 状态恢复

故障模型：分别处理进程、OS、SDK、固件、ASIC、链路、电源和管理网失效；明确故障域、保留状态、恢复目标与检测时间。

Warm restart：冻结/排空变更 → 保存必要状态 → 保留可保持的硬件转发 → 恢复映射 → reconcile → 恢复协议/学习；设置超时与 cold fallback。

一致性风险：软件成功但硬件未写入、重复创建、恢复依赖倒序、旧通知覆盖新态、OID/计数器变化；warm/fast/ISSU 名称不能证明零丢包。

升级韧性：Schema 迁移、双镜像/签名、版本互通、健康门槛、回滚及数据兼容；限流、隔离、watchdog、退避与容量余量防止级联故障。

安全与产品维护

信任边界：管理 API、SSH/SNMP、协议邻居、控制报文、租户与供应链；使用最小权限、RBAC/AAA、审计、管理 VRF/OOB 和服务隔离。

平台保护：Secure boot、签名升级、密钥管理、mTLS、敏感日志脱敏；保护固件回滚路径，检查构件来源和完整性。

网络与 API：CoPP/CPU policer、ACL、storm control、max-prefix、uRPF、邻居表保护；API 鉴权/schema/配额/限速/幂等，失败不留隐蔽部分状态。

长期维护：SBOM/CVE、许可证、依赖固定、LTS/backport、支持版本窗口、可复现构建；安全补丁需回归功能、性能、升级与回滚。

AI 通信与拓扑

并行方式：数据、张量、流水线、专家并行的消息尺寸、通信量、同步频率和拓扑敏感度不同；单一链路带宽不能代表训练效率。

Collectives [S7]：AllReduce 规约后分发；AllGather 收集后分发；ReduceScatter 规约后分片；另有 Broadcast/Reduce、点对点和 All-to-All 通信模式。

瓶颈链：GPU ↔ PCIe/NVLink ↔ NIC ↔ fabric；NUMA、GPU/NIC affinity、GPUDirect RDMA、incast、热点、微突发；barrier 放大慢 rank 的尾延迟。

验证变量：测 step time、GPU 等待、作业完成时间、有效带宽/p99；覆盖大小消息、多作业、多 rail、rank placement、Ring/Tree/分层算法和故障。

RDMA / RoCE

端点对象：QP、CQ、WQE/CQE、MR、lkey/rkey；Send/Receive、Read/Write、Atomic；可靠连接的 ACK/NAK、PSN、retry 与完成语义。

网络封装：RoCE v1 为 L2；v2 为 UDP/IP，可跨 L3，典型目的端口 4791。交换机通常按网络字段转发，不执行主机 verbs。

拥塞回路 [S8]：队列 ECN 标记 → 接收端 CNP → 发送端限速；DCQCN 为相关端点算法。PFC 按优先级暂停链路，映射与阈值需端到端匹配。

部署与排障：不把 RoCE 等同于必须全网 PFC；ECN-only/有损方案取决于端点与验证。检查 MTU、DSCP/PCP/TC、PFC/ECN/CNP、buffer drop、retry/QP。

性能公式

线速与排队：pps≈R/[8(L+20)]：R 为 bit/s，L 为含 FCS 帧长，20 为前导/SFD+IFG；100Gb/s、64B≈148.81Mpps。t_queue≈8Q/R，1MB@100Gb/s≈80µs。

BDP / Headroom：BDP=R×RTT/8；400Gb/s×10µs→500,000B。H≥R×T_stop/8+在途/帧/实现余量；T_stop 含检测、生成、传播与响应，BDP 不可直接作 headroom。

拓扑与恢复：超售≈下联总带宽/上联总带宽；恢复时间分解为检测、控制处理、硬件编程和流量恢复，并识别可并行阶段。

Ring AllReduce：T≈2(N−1)α+2(N−1)M/(N·B)：M 为每 rank 字节数，B 为有效 B/s，α 为每步延迟；未计计算、重叠和竞争。区分 bit/byte、MB/MiB 与有效负载。

验证矩阵与工具

验证层级：单元 → API contract → 模拟 ASIC → 仿真/FPGA → 真硬件 → 多交换机 → AI 负载；虚拟测试不证明真实资源与时序。

功能与压力：L2/L3/ACL/QoS/隧道、非法输入、满表、依赖和组合；最小帧/IMIX/Jumbo、全端口、route churn、MAC move、微突发和长期 soak。

故障与恢复：Link flap、进程 kill、SDK timeout、DB 断连、丢失/重复事件、firmware reset、OOM、电源/散热故障；检查恢复上界、回滚与软硬一致性。

工具与口径：Scapy/PTF、TRex、硬件流量仪、iperf3、RDMA perftest、nccl-tests；固定版本/拓扑/负载，报告置信区间；软件发生器受 CPU/NIC 限制。

可观测性与定位

分层定位：业务/collective → GPU/NIC → 链路 → 队列/转发 → 控制面 → SDK/ASIC；先确定范围、起点和最近变更，再逐层证伪。

数据面证据：Port packets/octets、CRC/FEC、drop reason、queue watermark/occupancy、ECN/PFC、ACL hit、镜像/采样和硬件表 dump。

控制面与关联：RIB/FIB/邻居、事件积压、API latency/failure、CPU/内存、对象数；关联 timestamp/request/OID/端口/版本，保留故障前窗口。

遥测陷阱：Counter/gauge/histogram、streaming、sFlow/INT；注意采样、重置/溢出、基数与时间同步。低平均利用率≠无突发，ping 正常≠RDMA 正常。

只读诊断命令

链路与路由：ip -s link；ip -d link；ip route show table all；ip -6 route；ip neigh；bridge fdb show；bridge vlan show。

端口与队列：ethtool <if>；ethtool -S <if>；ethtool -k <if>；tc -s qdisc show dev <if>；tc -s filter show dev <if> ingress。qdisc 不一定代表硬件队列。

设备与系统：devlink dev/port/resource/health show（分别执行）；dmesg -T；journalctl -k；ss -s；cat /proc/interrupts；tcpdump -ni <if> -s 0；perf top。

协议与 RDMA：vtysh -c "show bgp summary"；rdma link；ibv_devinfo。替换 <if>，核对版本/权限；reload、清计数、reset 与压测会改状态，仅在授权环境执行。

故障场景与证据

端口 up / 路由有但不通：查 VLAN/PVID、LAG/MTU、FEC、FDB/邻居、递归下一跳、ASIC 编程/资源、VRF/隧道和 ACL；对照入出口计数与软硬表。

性能退化 / PFC 风暴：查微突发、hash 热点、pause 传播、优先级/队列、ECN/CNP、NIC retry 和 GPU/PCIe；升级前后对齐配置/offload/固件再 A/B 回放。

UAF / 死锁：收集 core/trace、生命周期、退出/回调竞争与锁图；最小复现后使用 sanitizer/lockdep 验证修复、错误和并发路径。

表项震荡：查协议 flap、MAC move、重复/乱序通知、reconcile 互相覆盖、generation 与防抖；比较事件产生/消费速率并定位反馈环。

缩写与易混概念

交换与路由：ASIC 专用集成电路；SDK 软件开发套件；NOS 网络操作系统；SAI 交换抽象接口；FDB 转发表；RIB 路由信息库；FIB 转发信息库；TCAM 三态内容寻址存储。

Fabric 与拥塞：VRF 路由实例；VNI VXLAN 网络标识；VTEP 隧道端点；BUM 广播/未知单播/多播；ECMP 等价多路径；PFC 优先级流控；ECN 显式拥塞通知；CNP 拥塞通知包。

系统与 RDMA：DMA 直接内存访问；NUMA 非一致内存访问；RCU 读复制更新；QP 队列对；CQ 完成队列；MR 内存区域；MTU 最大传输单元；BDP 带宽时延积。

边界检查：PFC 流控≠ECN 标记；API 返回≠一定硬件生效；进程 HA≠转发不中断；IP 带宽≠应用带宽；可编程≠无限资源。每项追问状态、路径、上限、失败、观测与恢复。
