外层报头

Outer headers

Ethernet 14B；可选 VLAN；IPv4 最小 20B 或 IPv6 40B；UDP 8B，目的通常 4791；随后 BTH 12B。

Ethernet 14B, optional VLAN, IPv4 minimum 20B or IPv6 40B, UDP 8B typically to 4791, then 12B BTH.

IPv4 options/IPv6 extensions 会改变偏移，因此解析 RoCE 不能固定从字节 42 读取 BTH。

Options/extensions alter offsets, so parsers cannot universally read BTH at byte 42.

BTH / RETH / AETH

BTH / RETH / AETH

BTH 包含 opcode、P_Key、24bit destination QPN、24bit PSN 等。

BTH includes opcode, P_Key, 24-bit destination QPN and 24-bit PSN.

RETH 为 16B：VA 64bit、R_Key 32bit、DMA length 32bit；AETH 为 4B。扩展头由 opcode/分段位置决定，并非每个包都有 RETH。

RETH is 16B: 64-bit VA, 32-bit R_Key and 32-bit DMA length; AETH is 4B. Opcode/segment position selects extensions; not every packet contains RETH.

RDMA Write 分段

RDMA Write segmentation

RC Write First 可带 RETH，Middle 通常不重复 RETH，Last 结束该操作；Only 表示单包，带 immediate 的变体另含对应字段。

RC Write First can carry RETH; Middle generally does not repeat it; Last ends the operation; Only denotes a single packet, with immediate variants adding fields.

PSN 用于传输序列；它不证明某 NIC 必须先在 SRAM 重组所有 payload 再写内存。

PSN tracks transport order without implying a universal SRAM-based reassembly design.

ICRC / CNP / Retry

ICRC / CNP / retry

ICRC 4B 与 Ethernet FCS 4B 作用不同，ICRC 处理按规则规范化的相关头字段。

4B ICRC differs from 4B Ethernet FCS and accounts for protocol-defined normalization.

ECN→CNP→发送端调速构成拥塞回路；ACK/NAK、PSN、timeout/retry 提供相关传输机制，网络丢包与应用完成语义不能混同。

ECN→CNP→sender rate adjustment forms congestion feedback. ACK/NAK, PSN and retry mechanisms concern transport, not universal application-consumption guarantees.

RoCE 拥塞闭环

RoCE congestion loop

报文在交换机排队并被 ECN 标记，接收端产生 CNP，发送端拥塞算法更新速率，经过传输延迟后出口到达率才下降。分析回路要区分检测时间、反馈时间、算法反应与在途数据；PFC 是局部应急流控，不能自动替代端点拥塞控制。

Queued packets receive ECN marks, receivers generate CNP, sender algorithms adjust rates, and only after transit delay does egress arrival rate fall. Separate detection, feedback, algorithm response and in-flight traffic. PFC is local flow control, not an automatic replacement for endpoint congestion control.
