802.1Q 字段

802.1Q fields

基本 Ethernet 头 14B；VLAN tag 额外 4B，其中 TCI 为 PCP 3bit、DEI 1bit、VID 12bit。

Basic Ethernet headers are 14B; VLAN tags add 4B, with TCI containing PCP 3 bits, DEI 1 bit and VID 12 bits.

VID 0 用于 priority tagging，4095 保留；PCP 与内部 TC 的对应是配置关系，不是队列编号恒等。

VID 0 supports priority tagging and 4095 is reserved. PCP-to-internal-TC mapping is configured, not queue-number identity.

FDB 学习与泛洪

FDB learning & flooding

以源 MAC 和广播域学习入口，以目的 MAC 查出口。

Learn ingress from source MAC plus broadcast domain; look up destinations for egress.

未知单播/BUM 走该域的复制集合；老化与 MAC move 改变映射。源学习、目的查表、出口 VLAN 成员与 tag 改写是独立步骤，不能仅查 MAC 地址判断可达性。

Unknown unicast/BUM uses the domain's replication set; aging/moves change mappings. Learning, lookup, VLAN membership and tag rewriting are distinct steps.

LACP 与 hash

LACP & hashing

LACP 使用 Slow Protocols EtherType 0x8809 协商成员状态；collecting/distributing 表示收集/发送资格。

LACP uses Slow Protocols EtherType 0x8809 to negotiate member state; collecting/distributing represents eligibility.

数据流通常按 hash 选择成员，不由 LACP 逐包调度；单流速率可能受单成员限制。

Data normally follows member hashing rather than LACP per-packet scheduling. A single flow may be limited to one member's rate.

FEC / PCS / SerDes

FEC / PCS / SerDes

SerDes 负责串并转换和高速电信号，PCS 处理编码/块等逻辑，FEC 纠错。

SerDes handles high-speed serial signaling, PCS coding/block logic, and FEC correction.

区分 pre-FEC BER、纠错块与不可纠错块；纠错计数上升而 CRC 暂无错误可能表示链路裕量下降，并不直接证明已经丢包。

Distinguish pre-FEC BER, corrected and uncorrectable blocks. Rising correction with no CRC errors can indicate declining margin without proving current packet loss.

报文逐跳解释

Packet-by-packet explanation

入端口先决定允许的帧与 VLAN 归属，未打标签帧通常根据 PVID 分类。交换机以源 MAC 更新学习状态，再按目的 MAC 和广播域查询出口；出口规则决定标签保留或移除。抓到同一 MAC 不足以证明处于同一转发域，必须同时匹配 VLAN、bridge 和端口模式。

Ingress rules determine permitted frames and VLAN membership; untagged frames are commonly classified by PVID. Source MAC updates learning state, destination MAC plus broadcast domain determines egress, and egress rules retain/remove tags. Matching MAC alone does not imply the same forwarding domain: check VLAN, bridge and port mode.
