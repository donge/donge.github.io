开源项目

ClickFS

github.com/donge/clickfs 2026.5
用 Rust 编写的 FUSE 文件系统，将 ClickHouse 服务挂载为只读 POSIX 目录树。支持用 ls/cat/grep/head/tail 浏览数据库表、流式读取数据，无需 SQL 客户端。适配数据安全场景的只读审计与数据导出。发布至 crates.io，9 个版本。

ds4-ascend

github.com/donge/ds4-ascend 2026.5
将 Redis 作者 antirez 的 DeepSeek V4 Flash 推理引擎 ds4 移植到华为昇腾 Atlas 300i Duo NPU。实现 AscendC 自定义算子、CANN 运行时集成、GGUF 模型加载、weight/expert cache 管理。涉及模型加密加载与推理数据隔离。

TDX-ClickHouse

github.com/donge/tdx-clickhouse 2026.3
基于 Agentic Workflow 的通达信公式回测系统。将通达信技术指标自动转换为 ClickHouse SQL，大规模历史行情数据回测。结合 LLM Agent 实现自然语言→公式→SQL 转换链路。展示大数据分析与 AI 安全结合。

ZigHouse

github.com/donge/zighouse 2026.6
用 Zig 编写的列式 OLAP 引擎，兼容 ClickHouse MergeTree 存储格式与有线协议。编译期 SIMD 向量化、Morsel-driven parallelism、纯 Zig 手写 SQL 解析器。ClickBench 特殊优化版本排名第一。适配敏感数据加密存储与查询下推。

llama2.zig

github.com/donge/llama2.zig 2024
用纯 Zig 实现的 Llama2 LLM 推理引擎。从零手写张量运算、tokenizer、transformer 前向传播，无外部依赖。涉及模型量化、KV Cache 管理、推理数据加密隔离。

go-yyjson

github.com/donge/go-yyjson 2024
基于 yyjson C 库的 Go 高性能 JSON 解析绑定。零拷贝字符串视图、流式解析、DOM/SAX 双模式。性能较 encoding/json 提升 5-10 倍。适配高吞吐日志/审计数据解析场景。
